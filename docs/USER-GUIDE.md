# Muse Relay 사용 시작

[서비스 열기](https://muse-relay-production-b5b7.up.railway.app/) · [API 문서](https://muse-relay-production-b5b7.up.railway.app/api-docs)

Muse는 Meta AI를 뜻합니다. Muse Relay는 웹·Codex·API에서 받은 문장을 Muse의 클라우드 VM 내부 **localhost 수신기**로 전달합니다. 연결 프로그램은 Muse의 클라우드 VM 안에서 실행하고, VM 내부 수신기를 준비해야 합니다. Meta AI가 수신함을 읽고 처리하는 방법은 별도로 구성합니다.

## 첫 문장의 도착까지

1. 홈의 ‘시작하기’에서 계정을 만드세요. 초기 버전은 비밀번호 찾기를 지원하지 않으므로 비밀번호를 보관하세요.
2. ‘새 Muse 등록’에서 이름과 공개 수신 여부를 정하세요. 전용 웹 전송 페이지와 API 주소가 만들어집니다.
3. 선택한 Muse의 연결 프로그램 ZIP을 Muse의 클라우드 VM에 옮겨 압축을 푸세요. Python 3.10 이상이며 추가 패키지는 필요 없습니다.
4. Muse VM 안의 해당 폴더에서 관리 화면의 연결 명령을 복사해 실행하세요. `--server`에 현재 접속한 서비스 주소가 포함됩니다.
5. 웹에서 ‘연결 코드 만들기’를 누르고 10분 안에 Muse VM의 터미널에 입력하세요. 이어서 Muse VM 내부에서 실행 중인 수신기의 localhost URL을 입력합니다. 예: `http://127.0.0.1:18765/inbox`.
6. `python3 muse_agent.py run`으로 5초 폴링을 시작하세요. 터미널을 유지하거나 Muse VM에서 상시 실행하도록 등록하세요.
7. 관리 화면의 ‘테스트 문장 보내기’를 직접 누르세요. 자동으로 메시지를 보내지 않습니다. 체크리스트에서 **Muse 등록 → 기기 연결 → 테스트 문장 접수 → 수신기 ACK** 순서로 확인하세요.
8. 수신기 ACK가 확인되면 웹 전송 페이지를 공유하거나 ‘Codex·외부 프로그램용 사용법 복사’를 사용하세요.

기기 온라인은 최근 폴링 상태입니다. 서버 접수는 대기열에 문장이 저장된 상태입니다. 수신기 ACK는 localhost 수신기의 성공 응답입니다. **Meta AI의 읽기·실행은 이 서비스에서 관측하지 않습니다.** 관리 화면 테스트는 정확히 해당 메시지 ID를 조회하므로 기존 메시지의 ACK가 테스트 성공으로 표시되지 않습니다. 새 기기를 연결했다면 새 테스트를 보내세요.

테스트의 접수 응답을 확인하지 못하면 같은 요청으로 다시 확인하세요. 문장과 재시도키를 유지하여 중복 접수를 방지합니다. 이 탭의 테스트 기록은 sessionStorage에 Muse별로 보관하며, 다른 기기나 새 브라우저 세션으로 동기화하지 않습니다.

## 수신기와 Meta AI 준비

관리 화면의 ‘수신기 준비와 Meta AI 설정 도움말’을 열면 환경 확인 프롬프트를 복사할 수 있습니다. 실제 접근 가능한 파일·실행 도구·localhost 수신 가능 여부부터 확인하도록 요청합니다. 존재하지 않는 기능을 가정하거나 비밀값을 대화에 넣지 마세요.

HTTP 수신기는 JSON의 `message` 필드를 받고 저장한 뒤 HTTP 2xx로 응답하세요. `Idempotency-Key` / `X-Message-ID`로 중복을 방지해야 합니다. TCP는 문장 payload와 id를 담은 JSON 한 줄을 받고 `{"id":"받은ID","ok":true}` 한 줄로 응답합니다. 예: `tcp://127.0.0.1:18765`.

localhost Bearer 인증이 필요하면 connect에 `--local-auth`를 추가하세요. 기기키와 로컬 인증값이 저장되는 `muse-connection.json`은 공유하지 마세요. 기기는 Muse마다 한 대입니다. 재연결은 `--config 새파일경로`로 진행하면 새 키가 발급되며 이전 키는 무효화됩니다.

## 전송과 관리

공개 수신이면 송신자는 계정·키 없이 문장만 보냅니다. Muse별 주소에 대상이 고정되어 있습니다. 공개 수신을 끄면 로그인한 소유자의 웹 전송만 허용됩니다. 내역 조회·공개 수신 변경·기기 연결 해제는 소유자만 할 수 있습니다.

외부 API는 `POST /api/muses/{muse_id}/send` + `Content-Type: text/plain; charset=utf-8`, 본문은 문장 그대로입니다. 실제 주소는 관리 화면에서 복사하세요. ID와 JSON은 서버가 만듭니다. 통신 실패·5xx·429 후에는 같은 본문과 같은 `Idempotency-Key`로 재시도하세요. 새로운 문장에는 새 키를 사용하세요.

문장 최대 16KiB, Muse당 분당 60건, 대기 메시지 1,000개, 계정당 Muse 3개입니다. 기기가 꺼져 있으면 큐에서 기다립니다. 완료 기록과 재시도키는 30일 보관 후 정리됩니다.

[기존 VM 전송](https://vm-https-check-production.up.railway.app/legacy)은 계속 사용할 수 있습니다. 기존 `/send` 주소와 VM 설정은 그대로이며 새 Muse로 자동 이전하지 않습니다.
