# Muse에게 붙여넣어 연결하기

사용자가 명시적으로 승인한 흐름: Muse는 클라우드 환경을 다루는 AI 인터페이스다. 사용자는 터미널 설정 대신 웹에서 자신의 Muse를 등록하고 연결 프롬프트를 복사해 Muse에게 붙여넣는다. Muse가 자신의 환경을 확인하고 수신기 준비, 연결 프로그램 다운로드, 일회용 코드 교환, 폴링 시작과 결과 보고를 수행하도록 안내한다.

추천 구현은 기존 pairing API와 프로그램을 활용해 완성된 연결 프롬프트를 생성하는 것이다. 단순 정적 환경 확인 문구는 연결 정보가 부족하며, CLI만 추가하는 접근은 사용자의 수동 작업을 남긴다. 새 실행·Meta AI API를 만들지 않는다.

메인 연결 버튼은 유효한 10분 일회용 코드가 없으면 발급하고 서버 origin, ZIP 주소, 대상 Muse ID, 코드, 만료 시각, VM에서 수행할 정확한 작업과 검증 기준을 담아 복사한다. 유효한 프롬프트는 재사용하며, 명시적 새 발급·만료·연결 교체·연결 해제 시 갱신/폐기한다. 다른 Muse로 선택이 바뀐 동안 완료된 요청은 자동 복사하지 않는다. 코드와 프롬프트는 현재 페이지 메모리에만 보관하고 만료/연결 성공 시 표시를 지운다. 클립보드가 막히면 전체 프롬프트를 선택해 복사할 수 있게 한다.

프롬프트는 터미널/Python으로 실제 HTTPS 확인과 다운로드, 기존 VM 내부 수신기 탐색·재사용, 없을 때 loopback 전용 영속·중복방지 수신함 준비, API의 muse_agent.connect 사용, 예상 Muse ID 확인, 기존 설정/프로세스를 덮어쓰지 않는 실행, 수신 기록/ACK와 Muse 읽기·실행 구분을 지시한다. 코드 만료나 도구 제약은 사실대로 보고하고 새 프롬프트 요청/수동 확인 절차를 안내한다. 계정 비밀번호·장기 기기키를 넣거나 출력하지 않으며 일회용 코드만 대상 Muse와 공유한다. 공개 메시지 자체를 임의 작업 실행 권한으로 간주하지 않는다.

사용자 화면은 1. 프롬프트 복사 2. Muse에 붙여넣기 3. 웹에서 VM 연결/테스트 수신 확인이다. 프로그램 ZIP·CLI·localhost·수동 코드 입력은 보조 펼침 안내로 이동한다. 홈·FAQ·API 문서·사용 가이드도 이 흐름으로 맞춘다. 기존 VM·계정·API 계약을 유지한다. 실제 Meta AI의 도구 실행이나 자발적 주기 확인은 보장하지 않는다.
