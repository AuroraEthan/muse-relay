01 / CONNECT

내 기기 연결

Muse가 실행되는 컴퓨터에서 아래 순서대로 진행하세요.

  1. 연결 프로그램 다운로드 ↓압축을 풀고 터미널에서 해당 폴더를 여세요. Python 3.10 이상이 필요합니다.
  2. python3 muse_agent.py connect
    아래 연결 코드와 localhost 수신 주소를 입력하세요.
    10분 · 한 번 사용 가능
  3. python3 muse_agent.py run
    기기가 메시지를 가져와 localhost에 전달합니다.
연결되지 않음

기기는 Muse당 1대입니다. 새 기기 연결은 이전 연결을 교체합니다. localhost 인증이 필요하면 connect 명령에 --local-auth를 추가하세요.
