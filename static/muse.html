BEFORE YOU CONNECT

궁금한 점을
먼저 확인하세요.

Meta AI 계정을 연결하는 서비스인가요?

Meta AI의 공식 계정 연동 서비스가 아닙니다. Muse Relay는 Muse의 클라우드 VM 안에 있는 localhost 수신기까지 문장을 전달합니다. Meta AI가 그 수신함을 읽고 처리하는 방법은 VM 환경에서 따로 구성해야 합니다.

미리 준비할 것은 무엇인가요?

Muse의 클라우드 VM 안에 Python 3.10 이상과 HTTP 또는 TCP 수신기가 필요합니다. localhost 주소는 해당 VM 내부를 가리킵니다. 연결 프로그램에는 추가 Python 패키지가 필요 없습니다.

공개 주소를 아는 사람은 누구나 보낼 수 있나요?

공개 수신을 켠 경우 그렇습니다. 원하지 않으면 관리 화면에서 끄세요. 전송 내역은 로그인한 소유자만 볼 수 있습니다.

기기가 꺼져 있으면 어떻게 되나요?

문장은 대기열에 남습니다. 기기가 다시 폴링하고 수신기가 성공 응답을 보내면 수신기 ACK로 표시됩니다. 문장 16KiB, Muse당 분당 60건·대기 1,000개까지 지원합니다.

01 / CONNECT

Muse의 클라우드 VM 연결

아래 명령은 Muse의 클라우드 VM 안에서 실행하세요.

  1. 연결 프로그램 다운로드 ↓Muse의 클라우드 VM 안에서 압축을 풀고 터미널로 해당 폴더를 여세요. Python 3.10 이상이 필요합니다.
  2. python3 muse_agent.py connect
    아래 연결 코드와 Muse VM 내부의 localhost 수신 주소를 입력하세요.
    10분 · 한 번 사용 가능
  3. python3 muse_agent.py run
    Muse의 VM이 서버를 폴링해 VM 내부 localhost 수신기에 전달합니다.
연결되지 않음
수신기 준비와 Meta AI 설정 도움말

HTTP 예: http://127.0.0.1:18765/inbox. JSON의 message를 받고 저장 후 HTTP 2xx로 응답하세요. TCP 예: tcp://127.0.0.1:18765. 받은 ID와 ok:true를 JSON 한 줄로 응답해야 합니다. 메시지 ID로 중복 처리를 막으세요.

연결 프로그램은 5초마다 서버를 조회합니다. 이 프로그램은 Muse의 클라우드 VM 안에서 실행합니다. Meta AI가 수신함을 읽고 처리하는 절차는 별도 구성합니다. 아래 프롬프트로 실제 환경에서 가능한 연결 방법부터 확인하세요.

일회용 코드와 기기키·로컬 인증값을 대화에 붙여넣지 마세요. 기기키가 저장된 muse-connection.json도 공유하지 마세요.

기기는 Muse당 1대입니다. 새 기기 연결은 이전 연결을 교체합니다. localhost 인증이 필요하면 connect 명령에 --local-auth를 추가하세요.
