BEFORE YOU CONNECT

궁금한 점을
먼저 확인하세요.

Meta AI 계정을 연결하는 서비스인가요?

Muse는 클라우드 환경에서 작업하는 AI 인터페이스입니다. 당신은 연결 프롬프트를 Muse에게 전달하고, Muse는 자신의 환경을 확인해 수신함과 연결 프로그램을 준비합니다. Relay는 문장을 그 수신함으로 전달합니다. 실제 Muse의 읽기·작업 결과는 Muse에게 확인하세요.

미리 준비할 것은 무엇인가요?

Muse와 대화할 수 있으면 시작할 수 있습니다. 프롬프트가 Muse에게 터미널·Python 3.10 이상·네트워크·수신함을 확인하도록 요청합니다. 필요한 도구를 사용할 수 없는 환경이면 Muse가 제약을 알려주도록 안내합니다.

어떤 Muse에게 보내는지 어떻게 구분하나요?

Muse마다 다른 송신 API 키를 발급합니다. 공통 API에 키와 문장을 보내면 그 키에 연결된 Muse로 전달됩니다. 주소만으로는 보낼 수 없습니다. 송신 키로는 내역 조회나 기기 관리를 할 수 없으며, 소유자가 키를 교체하거나 폐기할 수 있습니다.

VM이 재시작해도 다시 연결되나요?

쉬는 동안 문장은 서버 대기열에 남습니다. 연결 프롬프트는 Muse에게 영구 저장 경로와 부팅 시 자동 시작을 설정하고, 수신기·중계기·메시지 처리를 재개하도록 요청합니다. 정상 재시작과 복구는 로그에만 남기고, 사용자 조치가 필요한 장애만 알리도록 안내합니다. 실제 자동 시작 지원과 복구 검증 결과는 Muse가 확인해야 합니다. 수신기 ACK는 Muse의 작업 완료와 별도입니다. 문장 16KiB, Muse당 분당 60건·대기 1,000개까지 지원합니다.

    연결 프롬프트 복사선택한 Muse의 서버 주소와 10분 일회용 코드가 자동으로 들어갑니다.
  2. 2
    Muse 대화에 붙여넣기Muse가 연결과 부팅 시 자동 시작, 수신함 확인·메시지 처리 재개를 설정하고 검증합니다.
  3. 3
    이 화면에서 도착 확인Muse가 준비됐다고 알려주면 ‘테스트 문장 보내기’를 눌러주세요.

재시작 후에도 이어서: 저장된 설정과 처리 기록으로 복구하도록 요청합니다. 정상 복구는 조용히, 사용자 조치가 필요한 장애만 알리도록 안내합니다. 실제 적용 결과는 Muse가 확인합니다.

프롬프트를 만들어 Muse에게 전달하세요.

일회용 코드는 연결할 Muse에게만 전달하세요. 연결할 때 기존 기기 연결은 교체됩니다. 장기 기기키와 비밀번호는 프롬프트에 포함되지 않습니다.

연결되지 않음
직접 설정하기 · 고급 안내

직접 실행할 때만 아래 안내를 사용하세요. 명령은 Muse의 클라우드 VM 안에서 실행합니다.

  1. 연결 프로그램 다운로드 ↓VM 안에서 압축을 풀고 해당 폴더를 여세요. Python 3.10 이상이 필요합니다.
  2. python3 muse_agent.py connect
    프롬프트를 발급하면 아래에 코드가 표시됩니다. VM 내부 수신 주소와 함께 입력하세요.
    10분 · 한 번 사용 가능
  3. python3 muse_agent.py run

HTTP 예: http://127.0.0.1:18765/inbox. VM 내부 수신기가 JSON의 message를 영속 저장하고 중복 ID를 처리한 뒤 HTTP 2xx로 응답해야 합니다. TCP는 받은 id와 ok:true를 담은 JSON 한 줄로 응답합니다.

localhost Bearer 인증이 필요하면 connect에 --local-auth를 추가하세요. 기기키가 저장된 muse-connection.json은 공개하지 마세요.
